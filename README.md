## 🧩 Featured Projects

### 🩺 [MedVision AI](https://github.com/harizonelopez/Medical-Vision-AI)
A deep learning application for pneumonia classification from chest X-ray images, featuring model predictions and Grad-CAM visual explanations.

**Technologies:** Python, PyTorch, ResNet18, Streamlit, Grad-CAM.

### 🏡 [EstateAgency](https://github.com/harizonelopez/EstateAgency)
A Django-based real estate platform featuring property listings, agent profiles, enquiry management, and email notifications.

**Technologies:** Python, Django, SQLite, Bootstrap, HTML, CSS.

### 🏛️ [Civic Reporting System](https://github.com/harizonelopez/Civic_system-murang-a-county)
A web application designed to support reporting and management of civic issues within Murang'a County.

**Technologies:** Python, Flask, SQLAlchemy, Bootstrap.
